{{ snippet:header }}
    The Original Goal of this Resourcepack is to enable Default Connected Textures inspired by the default textures optifine has onto Fusion.
    With this & Fusion you can run default connected textures without continuity or optifine
    . This pack could be implied to be connected textures with "Fabulous Graphics" since Panes and Grates connect near perfectly

Features?

  • Fancy Glass Panes CT
  • Glass Block CT
  • Red/Normal Sandstone CT
  • Chiseled/Normal Bookshelf CT
  • Copper Blocks and Grates CT (with their variants too)
  • "CT" Stands for Connected Textures

FAQ

  • Addons?
  • No connected textures? -> look at the top of the modpage!
  • "made for an older version of Minecraft" -> just load the pack as normal and it should run fine unless mojang has made significant changes to their resourcepack format
  • Make sure you have the correct version for your version and correct version of Fusion
  • Breaks with sodium pre 0.6.0 without indium, this is mostly because sodium (not embeddium) changes the fabric rendering system so indium fixes that

Why only Fusion?

  • Fusion offers many features which are required for custom connected textures, observe block surroundings, implementing specific culling, etc
  • CTM and Athena Compat did exist at the start but are Depricated; optifine/continuity do not support enough features
